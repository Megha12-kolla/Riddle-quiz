# 🧠 Riddle Quiz

A fun and interactive **Python riddle quiz game** that challenges users with 10 riddles, checks their answers, calculates their score and percentage, and provides performance feedback. 🧩🎯

## ✨ Features

- 👤 Personalized welcome message
- 🧩 10 different riddles
- ✅ Automatic answer checking
- 🔄 Supports multiple correct answers
- 🏆 Score calculation
- 📊 Percentage calculation
- 🌟 Performance-based feedback

## 🛠️ Technologies Used

- 🐍 Python
- 📋 Lists
- 📖 Dictionaries
- 🔁 For loops
- 🔀 Conditional statements
- ⌨️ User input
- 🧮 Basic calculations

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python quiz.py
